Arrow Functions

This function takes a string and turns it into uppercase. I got this idea from the slides where I practiced converting a simple function step by step into an arrow function.

Named Function

            function makeUpperCase(aString) {
                return aString.toUpperCase();
            }

Function Expression

            const makeUpperCase = function(aString) {
                return aString.toUpperCase();
            };

Arrow Function

            const makeUpperCase = (aString) => {
                return aString.toUpperCase();
            };
